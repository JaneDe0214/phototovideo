# 相簿轉 8K/4K YouTube 極致備份影片合成工具

專為備份大量相片與影片至 YouTube 所設計的 Windows 桌面應用程式。採用「**最高流量、最高規格箱子（Container/Bitrate/Resolution）**」概念，使上傳至 YouTube 的相片在線上串流或暫停截圖時達到最低失真度，並能讓 YouTube 官方伺服器原生接收最高等級的 VP9 / AV1 串流轉碼通道。

---

## 核心亮點特色

1. **最高視訊規格箱子（8K UHD 60FPS, 240 Mbps, 10-bit）**：
   - 支援最高 8K (`7680 × 4320`) 60 FPS 輸出，達到 YouTube 官方所認可的最高建議位元率 **240 Mbps**。
   - 採用 **Lanczos 頂級銳利縮放演算法**，相片在重取樣至 8K 畫布時邊緣極度銳利。
   - 強制每張相片首影格插入 **IDR 關鍵影格 (Keyframe / GOP)**，確保使用者在 YouTube 播放時隨手暫停截圖，截取的每一張都是無時間壓縮偽影的純靜態畫面！
   - 智慧直橫構圖填補：預設啟用**毛玻璃模糊背景**，主畫面忠實還原原生比例不變形。

2. **最高音訊規格箱子（AAC-LC 512 kbps, 48,000 Hz 立體聲）**：
   - 採用 YouTube 立體聲最高位元率上限 **512 kbps** 與 **48 kHz** 高取樣率。
   - 相片展示期間自動無縫補齊乾淨靜音軌，與影片段落的原音軌精準對齊，徹底根除音畫不同步與接縫爆音。

3. **硬體智慧雙向適配（UHD 770 桌機 vs Core Ultra 255H 筆電）**：
   - **在 Core Ultra 255H / 155H 筆電**：自動解鎖 **Intel Arc GPU 8K AV1 / 8K HEVC 硬體極速編碼 (`av1_qsv` / `hevc_qsv`)**，享受硬體狂飆轉碼！
   - **在 Intel UHD Graphics 770 桌機**：自動啟用 **4K 60FPS HEVC 雙多媒體引擎 QSV 極速硬體加速 (100 Mbps)**；若選用 8K 則自動啟用 CPU 視覺無損高畫質排程。

4. **自訂起點打包單一影片 ＋ 自動生成 YouTube 章節時間軸（Chapters.txt）**：
   - 樹狀目錄清晰展現各子資料夾的相片數、影片數與容量。
   - 支援點擊任意資料夾作為「合成起點」，自動遞迴該起點底下的所有子資料夾媒體，依據 EXIF 拍攝時間精確串接。
   - 自動在輸出目錄生成同名 `_Chapters.txt`，直接複製貼上至 YouTube 說明欄即可啟用影片章節進度條！

---

## 執行需求

- 作業系統：Windows 10 / 11 64-bit
- 執行環境：Python 3.11+
- 核心引擎：FFmpeg 6.0+（內建自動偵測系統或 Winget 安裝路徑）

---

## 快速啟動

直接雙擊執行目錄下的 `run.bat`，或在命令列執行：

```powershell
python app.py
```
